# ACIRA-X: Autonomous Cyber Incident Response for Attacks

ACIRA-X is a modern, AI-powered Security Operations Center (SOC) dashboard and incident response simulation platform. It serves as a proof-of-concept for the future of autonomous cybersecurity. 

Instead of relying solely on human analysts to manually sift through alerts and respond to threats, ACIRA-X demonstrates an automated workflow where AI agents detect anomalies, investigate logs, analyze risk, execute containment actions, and generate comprehensive post-mortem reports—all in real-time.

---

## 🛠️ Tech Stack

This project is divided into two decoupled parts:

### Frontend
* **Framework:** Next.js 16 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS (configured for a dark, glassmorphism UI)
* **Components:** shadcn/ui & Radix UI primitives
* **Icons:** Lucide React

### Backend
* **Framework:** FastAPI
* **Language:** Python 3
* **Database:** SQLite (managed via SQLAlchemy ORM)
* **Background Processing:** FastAPI BackgroundTasks for handling simulated agent workflows.

## 🚀 How to Run

To run the application locally, you will need two terminal windows to start both the backend server and the frontend application.

### 1. Start the Backend
Open a terminal and navigate to the backend directory:
```bash
cd acira-x-backend
```
If you haven't already, activate the virtual environment and install dependencies (assuming `venv` is set up):
```bash
.\venv\Scripts\activate
pip install -r requirements.txt
```
Run the FastAPI server:
```bash
uvicorn main:app --reload --port 8000
```
*The backend API will be available at `http://localhost:8000`.*

### 2. Start the Frontend
Open a second terminal and navigate to the frontend directory:
```bash
cd acira-x-frontend
```
Install the Node dependencies (if you haven't yet):
```bash
npm install
```
Start the Next.js development server:
```bash
npm run dev
```
*The web application will be available at `http://localhost:3000`.*

## 🌟 Core Features

ACIRA-X features several distinct pages, each mimicking a critical part of a modern enterprise SOC platform:

### 1. Dashboard (Home)
* **What it does:** Provides a high-level, birds-eye view of your security posture.
* **What it shows:** Live metrics (Active Incidents, Critical Alerts, Devices Protected, Threat Blocks), a visual threat map, a timeline of recent incidents, and a real-time feed of detected threats.

### 2. Protected Files
* **What it does:** Allows users to simulate uploading sensitive assets (like proprietary data or certificates) to place them under active ACIRA-X monitoring.
* **What it shows:** A list of protected files alongside their SHA-256 hashes. **If you run a Ransomware simulation, these files will dynamically show as "Compromised"**, demonstrating how the system tracks data at risk before restoring it.

### 3. Response Center (Simulations)
* **What it does:** The control hub for launching simulated cyberattacks to test the autonomous response engine.
* **What it shows:** Interactive playbooks for 4 major attack vectors:
  * **🎣 Phishing Simulation:** Tests credential harvesting and account lockout.
  * **🔨 Hydra Brute Force (SSH):** Tests server login attacks and IP blocking.
  * **🔐 Ransomware (LockBit 3.0):** Tests mass file encryption and backup recovery.
  * **💉 SQL Injection (Web App):** Tests WAF evasion and database exfiltration.
* *Launching these triggers a live, multi-agent AI response visible across the platform.*

### 4. Incidents
* **What it does:** Tracks major security events that require multi-step remediation.
* **What it shows:** An interactive, filterable list of incidents. Expanding an incident reveals the **Live AI Agent Activity Log**, showing exactly how the Detection, Investigation, Analysis, Response, and Recovery agents are handling the threat second-by-second.

### 5. Security Alerts
* **What it does:** A raw feed of individual security events and anomalies detected across the network.
* **What it shows:** Individual alerts categorized by severity (Low to Critical). New alerts can be manually "Acknowledged" by the user.

### 6. Endpoints
* **What it does:** Manages the devices and servers connected to the network.
* **What it shows:** A list of endpoints (Windows, macOS, Ubuntu). You can view their live risk level and manually **Isolate** or **Reconnect** them. During simulations, the AI will autonomously isolate compromised endpoints here.

### 7. Threat Intelligence
* **What it does:** Tracks known global threat actors, campaigns, and Indicators of Compromise (IOCs).
* **What it shows:** Active global threat campaigns (e.g., LockBit, DarkGate) and a searchable database of malicious IPs, file hashes, and domains.

### 8. SOC Reports
* **What it does:** The final step of the incident response lifecycle.
* **What it shows:** Autogenerated post-mortem reports created by the AI after an incident is resolved. These include an executive summary, a timestamped timeline, MITRE ATT&CK framework mapping, and actionable remediation steps.

## 🏢 System Scope: Single vs. Multi-System

ACIRA-X is designed as a **Multi-System Platform**. 

While this MVP is a simulated proof-of-concept running locally, the architecture and UI are designed to manage an entire enterprise network. It monitors multiple endpoints (servers, employee laptops), ingests alerts from various network appliances (firewalls, WAFs), and coordinates incident response across the entire infrastructure domain, rather than just protecting a single local computer.

---

## 📈 Advantages

1. **Speed of Response:** Autonomous agents can isolate a compromised machine and sever network connections in milliseconds, compared to the minutes or hours it takes human analysts.
2. **Reduced Alert Fatigue:** By having AI automatically investigate and correlate low-level alerts into a single "Incident", human operators aren't overwhelmed by false positives.
3. **Continuous Operation:** The AI SOC never sleeps, providing consistent 24/7/365 monitoring and response capabilities without performance degradation.
4. **Standardized Remediation:** Automated playbooks ensure that the response to a specific threat (like Ransomware) is handled perfectly according to best practices every single time.

## 🔮 Future Scope

While the current version relies on simulated data and hardcoded agent workflows to demonstrate the concept, future iterations could evolve into a production-ready tool:

1. **Real-World Agent LLM Integration:** Connect the "Agents" to actual Large Language Models (like Claude or GPT-4) to dynamically analyze real log files instead of using simulated scripts.
2. **Live Telemetry Ingestion:** Hook the backend up to real SIEM tools (Splunk, Elastic) or EDR agents (CrowdStrike, SentinelOne) via APIs to process live, real-world network data.
3. **Actual Network Execution:** Allow the Response Agent to make real API calls to firewalls (to block IPs) or Active Directory (to suspend real users).
4. **Custom Playbook Builder:** Implement a UI that allows security engineers to drag-and-drop their own automated response workflows without writing code.
